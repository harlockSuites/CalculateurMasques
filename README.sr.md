# IPv4 Калкулатор Мрежних Маски

[Français](README.md) · [English](README.en.md) · [Español](README.es.md) · [Português](README.pt.md) · [Italiano](README.it.md) · **Српски** · [Polski](README.pl.md) · [Magyar](README.hu.md) · [Русский](README.ru.md) · [हिन्दी](README.hi.md) · [中文](README.zh.md) · [Tiếng Việt](README.vi.md) · [한국어](README.ko.md) · [日本語](README.ja.md) · [Filipino](README.fil.md)

Графички алат који ради **ван мреже**, бесплатан и отвореног кода, за израчунавање IPv4 маски подмрежа, поделу мреже на подмреже, чување историје и њен извоз. Интерфејс на **15 језика**.

Репозиторијум: <https://github.com/harlockSuites/CalculateurMasques>

---

## Преглед

Апликација је организована у три картице:

| Картица | Садржај |
|---|---|
| **Калкулатор** | Главно израчунавање, IP конверзије, провера припадности |
| **Подела** | Аутоматска подела мреже на подмреже |
| **Историја** | Бележење израчунавања, извоз у CSV / TXT |

## Функционалности

### Картица Калкулатор
- Унос преко **CIDR префикса** (`/24`) или **децималне маске** (`255.255.255.0`) — оба се аутоматски синхронизују
- Приказани резултати:
  - Адреса мреже
  - Маска подмреже
  - CIDR нотација
  - Wildcard маска
  - Прва / Последња адреса хоста
  - Broadcast адреса
  - Број употребљивих хостова
  - Потпуни опсег мреже
- **Конверзије** унете IP адресе: децимална нотација са тачкама, бинарно, хексадецимално, децимално (32-битни цео број)
- **Провера припадности**: проверава да ли задата IP адреса припада израчунатој мрежи
- **Десни клик** на било коју вредност за копирање у привремену меморију
- Тастер **Enter** за покретање израчунавања

### Картица Подела
- Подела мреже на N једнаких подмрежа
- Или налажење минималног CIDR-а који може да садржи N хостова
- Табела подмрежа са мрежом, маском, хостовима, broadcast-ом (ограничена на 65 536 редова, а изнад тога се приказује порука на изабраном језику)
- Десни клик на ћелију за копирање вредности

### Картица Историја
- Свако израчунавање се аутоматски бележи, заједно са временом израчунавања
- Двоструки клик на унос за његово поновно учитавање у калкулатор
- Извоз **CSV** (UTF-8 кодирање са BOM-ом, компатибилно са Excel-ом)
- Извоз **TXT** (читљив формат)

## Предуслови

- **Windows 10 / 11**
- **Python 3.8+** — [python.org](https://www.python.org/downloads/)
- Модул `tkinter` (укључен у стандардну инсталацију Python-а)

За покретање скрипте није потребна ниједна спољна зависност. [Pillow](https://pypi.org/project/pillow/) је опционалан: служи искључиво за приказ иконе прозора у пуној резолуцији.

## Покретање

### Преко Python-а
```
python calculateur_masques.py
```

### Преко компајлираног извршног фајла
Двапут кликните на `dist\CalculateurMasquesIPv4.exe`. Извршни фајл је самосталан, без инсталације. Није верзиониран у овом репозиторијуму: компајлирајте га (видети испод).

---

## Компајлирање извршног фајла

Репозиторијум садржи PyInstaller спецификацију (`CalculateurMasquesIPv4.spec`) која уграђује икону, банер и преводе. Из овог директоријума:

```
pip install pyinstaller pillow
python -m PyInstaller --clean --noconfirm CalculateurMasquesIPv4.spec
```

Извршни фајл се генерише у директоријуму `dist\`. Икона (`icon.ico`) је уграђена у exe.

## Подржани посебни случајеви

| Префикс | Понашање |
|---|---|
| `/31` | Веза тачка-тачка (RFC 3021) — 2 адресе, без конвенционалног broadcast-а |
| `/32` | Један хост — прва = последња = адреса мреже |
| `/0` | Универзална мрежа `0.0.0.0` |
