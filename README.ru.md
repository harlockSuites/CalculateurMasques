# Калькулятор масок подсетей IPv4

[Français](README.md) · [English](README.en.md) · [Español](README.es.md) · [Português](README.pt.md) · [Italiano](README.it.md) · [Српски](README.sr.md) · [Polski](README.pl.md) · [Magyar](README.hu.md) · **Русский** · [हिन्दी](README.hi.md) · [中文](README.zh.md) · [Tiếng Việt](README.vi.md) · [한국어](README.ko.md) · [日本語](README.ja.md) · [Filipino](README.fil.md)

**Автономная** (без доступа в интернет), бесплатная утилита с открытым исходным кодом и графическим интерфейсом: вычисляет маски подсетей IPv4, разбивает сеть на подсети, ведёт историю вычислений и позволяет её экспортировать. Интерфейс доступен на **15 языках**.

Репозиторий: <https://github.com/harlockSuites/CalculateurMasques>

---

## Обзор

Приложение состоит из трёх вкладок:

| Вкладка | Содержимое |
|---|---|
| **Калькулятор** | Основной расчёт, конвертация IP-адресов, проверка принадлежности |
| **Разделение** | Автоматическое разбиение сети на подсети |
| **История** | Журнал вычислений, экспорт в CSV / TXT |

---

## Возможности

### Вкладка Калькулятор
- Ввод **префикса CIDR** (`/24`) или **десятичной маски** (`255.255.255.0`) — оба поля синхронизируются автоматически
- Отображаемые результаты:
  - Адрес сети
  - Маска подсети
  - Нотация CIDR
  - Обратная маска (wildcard)
  - Первый / Последний адрес хоста
  - Широковещательный адрес (broadcast)
  - Количество используемых хостов
  - Полный диапазон сети
- **Конвертация** введённого IP-адреса: десятичная запись с точками, двоичное, шестнадцатеричное, десятичное (32-битное целое)
- **Проверка принадлежности**: проверяет, принадлежит ли заданный IP-адрес вычисленной сети
- **Правый клик** по любому значению копирует его в буфер обмена
- Клавиша **Enter** запускает вычисление

### Вкладка Разделение
- Разбиение сети на N равных подсетей
- Или поиск минимального CIDR, вмещающего N хостов
- Таблица подсетей с сетью, маской, хостами, broadcast (не более 65 536 строк; при превышении выводится сообщение на выбранном языке)
- Правый клик по ячейке копирует значение

### Вкладка История
- Каждое вычисление автоматически сохраняется вместе со временем расчёта
- Двойной клик по записи загружает её обратно в калькулятор
- Экспорт в **CSV** (кодировка UTF-8 с BOM, совместимо с Excel)
- Экспорт в **TXT** (удобочитаемый формат)

### Выбор языка
Доступно 15 языков; выбор осуществляется в заголовке приложения:

| Группа | Языки |
|---|---|
| Романские | Français · English · Español · Português · Italiano |
| Центральная/Восточная Европа | Српски · Polski · Magyar · Русский |
| Южная/Восточная Азия | हिन्दी · 中文 · Tiếng Việt · 한국어 · 日本語 · Filipino |

Язык переключается мгновенно, без перезапуска.

### Кнопка О программе
Рядом с выбором языка кнопка **О программе** открывает окно с баннером автора (`banner.png`) и сообщением «Эта автономная утилита бесплатна и имеет открытый исходный код.», переведённым на все 15 языков.

## Требования

- **Windows 10 / 11**
- **Python 3.8+** — [python.org](https://www.python.org/downloads/)
- Модуль `tkinter` (входит в стандартную установку Python)

Для запуска скрипта внешние зависимости не требуются. [Pillow](https://pypi.org/project/pillow/) необязателен: он нужен только для отображения значка окна в полном разрешении.

Дважды щёлкните `dist\CalculateurMasquesIPv4.exe`. Исполняемый файл автономен и не требует установки. В этом репозитории он не хранится под контролем версий: скомпилируйте его сами (см. ниже).

## Сборка исполняемого файла

Репозиторий содержит spec-файл PyInstaller (`CalculateurMasquesIPv4.spec`), который включает в сборку значок, баннер и переводы. Из этой папки выполните:

```
pip install pyinstaller pillow
python -m PyInstaller --clean --noconfirm CalculateurMasquesIPv4.spec
```

Исполняемый файл создаётся в папке `dist\`. Значок (`icon.ico`) встраивается в exe.

## Обрабатываемые особые случаи

| Префикс | Поведение |
|---|---|
| `/31` | Канал точка-точка (RFC 3021) — 2 адреса, без обычного broadcast |
| `/32` | Единственный хост — первый = последний = адрес сети |
| `/0` | Универсальная сеть `0.0.0.0` |
