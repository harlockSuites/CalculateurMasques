# IPv4 सबनेट मास्क कैलकुलेटर

[Français](README.md) · [English](README.en.md) · [Español](README.es.md) · [Português](README.pt.md) · [Italiano](README.it.md) · [Српски](README.sr.md) · [Polski](README.pl.md) · [Magyar](README.hu.md) · [Русский](README.ru.md) · **हिन्दी** · [中文](README.zh.md) · [Tiếng Việt](README.vi.md) · [한국어](README.ko.md) · [日本語](README.ja.md) · [Filipino](README.fil.md)

**ऑफ़लाइन**, निःशुल्क और ओपन-सोर्स ग्राफ़िकल उपयोगिता, जिससे IPv4 सबनेट मास्क की गणना की जा सकती है, किसी नेटवर्क को सबनेट में विभाजित किया जा सकता है, इतिहास रखा जा सकता है और उसे निर्यात किया जा सकता है। इंटरफ़ेस **15 भाषाओं** में उपलब्ध है।

रिपॉज़िटरी: <https://github.com/harlockSuites/CalculateurMasques>

## विशेषताएँ

### कैलकुलेटर टैब
- **CIDR उपसर्ग** (`/24`) या **दशमलव मास्क** (`255.255.255.0`) द्वारा इनपुट — दोनों अपने-आप समन्वित (सिंक) रहते हैं
- प्रदर्शित परिणाम:
  - नेटवर्क पता
  - सबनेट मास्क
  - CIDR संकेतन
  - वाइल्डकार्ड मास्क
  - पहला / अंतिम होस्ट पता
  - ब्रॉडकास्ट पता
  - उपयोगी होस्ट की संख्या
  - पूर्ण नेटवर्क श्रेणी
- दर्ज किए गए IP पते के **रूपांतरण**: बिंदु दशमलव संकेतन, द्विआधारी, हेक्साडेसिमल, दशमलव (32-बिट पूर्णांक)
- **सदस्यता जाँच**: परखता है कि दिया गया IP गणना किए गए नेटवर्क से संबंधित है या नहीं
- किसी भी मान पर **राइट-क्लिक** करके उसे क्लिपबोर्ड पर कॉपी करें
- गणना शुरू करने के लिए **Enter** कुंजी

### विभाजन टैब
- किसी नेटवर्क को N समान सबनेट में विभाजित करना
- या N होस्ट समाहित करने के लिए न्यूनतम CIDR खोजना
- सबनेट की तालिका, जिसमें नेटवर्क, मास्क, होस्ट, ब्रॉडकास्ट दिए जाते हैं (अधिकतम 65 536 पंक्तियाँ; इससे अधिक होने पर चुनी हुई भाषा में संदेश दिखता है)
- मान कॉपी करने के लिए किसी सेल पर राइट-क्लिक करें

### इतिहास टैब
- प्रत्येक गणना गणना के समय के साथ अपने-आप दर्ज हो जाती है
- किसी प्रविष्टि को कैलकुलेटर में फिर से लोड करने के लिए उस पर डबल-क्लिक करें
- **CSV** निर्यात (BOM के साथ UTF-8 एन्कोडिंग, Excel के अनुकूल)
- **TXT** निर्यात (पठनीय प्रारूप)

## निष्पादन योग्य फ़ाइल संकलित करना

रिपॉज़िटरी में एक PyInstaller स्पेक (`CalculateurMasquesIPv4.spec`) दी गई है, जो आइकन, बैनर और अनुवादों को अंतर्निहित करती है। इस फ़ोल्डर से:

```
pip install pyinstaller pillow
python -m PyInstaller --clean --noconfirm CalculateurMasquesIPv4.spec
```

निष्पादन योग्य फ़ाइल `dist\` फ़ोल्डर में बनती है। आइकन (`icon.ico`) exe में समाहित है।
