# Калькулятор масок подсетей IPv4 — Linux

[Français](../README-LINUX.md) · [English](README-LINUX.en.md) · [Español](README-LINUX.es.md) · [Português](README-LINUX.pt.md) · [Italiano](README-LINUX.it.md) · [Српски](README-LINUX.sr.md) · [Polski](README-LINUX.pl.md) · [Magyar](README-LINUX.hu.md) · **Русский** · [हिन्दी](README-LINUX.hi.md) · [中文](README-LINUX.zh.md) · [Tiếng Việt](README-LINUX.vi.md) · [한국어](README-LINUX.ko.md) · [日本語](README-LINUX.ja.md) · [Filipino](README-LINUX.fil.md)

> **Ветка `Linux`**: версия программы для Linux. Ветка `main` зарезервирована для дистрибутива Windows; не сливайте одну ветку в другую.

Графическая утилита для вычисления масок подсетей IPv4 с поддержкой 15 языков, разбиением на подсети, историей и экспортом.

Репозиторий: <https://github.com/harlockSuites/CalculateurMasques/tree/Linux>

---

## Обзор

Приложение состоит из трёх вкладок:

| Вкладка | Содержимое |
|---|---|
| **Калькулятор** | Основной расчёт, конвертация IP-адресов, проверка принадлежности |
| **Разделение** | Автоматическое разбиение сети на подсети |
| **История** | Журнал вычислений, экспорт в CSV / TXT |

---

## Возможности

### Вкладка Калькулятор
- Ввод **префикса CIDR** (`/24`) или **десятичной маски** (`255.255.255.0`) — оба поля синхронизируются автоматически
- Отображаемые результаты:
  - Адрес сети
  - Маска подсети
  - Нотация CIDR
  - Обратная маска (wildcard)
  - Первый / Последний адрес хоста
  - Широковещательный адрес (broadcast)
  - Количество используемых хостов
  - Полный диапазон сети
- **Конвертация** введённого IP-адреса: десятичная запись с точками, двоичное, шестнадцатеричное, десятичное (32-битное целое)
- **Проверка принадлежности**: проверяет, принадлежит ли заданный IP-адрес вычисленной сети
- **Правый клик** по любому значению копирует его в буфер обмена
- **Обратная маска** (wildcard, напр. `0.0.0.255`) отклоняется с переведённым сообщением: введите маску подсети (`255.255.255.0`)
- **Колесо мыши**: прокручивает страницу независимо от того, над каким элементом находится курсор (X11: `Button-4`/`Button-5`; Wayland: `MouseWheel`)
- Клавиша **Enter** запускает вычисление

### Вкладка Разделение
- Разбиение сети на N равных подсетей
- Или поиск минимального CIDR, вмещающего N хостов
- Таблица подсетей с сетью, маской, хостами, broadcast
- Предел в 65 536 подсетей за одно разбиение (при превышении выводится сообщение, а интерфейс не зависает)
- Правый клик по ячейке копирует значение

### Вкладка История
- Каждое вычисление автоматически сохраняется вместе со временем расчёта (оно сохраняется при отображении и экспорте)
- Двойной клик по записи загружает её обратно в калькулятор
- Экспорт в **CSV** (кодировка UTF-8)
- Экспорт в **TXT** (удобочитаемый формат)

### Выбор языка
Доступно 15 языков; выбор осуществляется в заголовке приложения:

| Группа | Языки |
|---|---|
| Романские | Français · English · Español · Português · Italiano |
| Центральная/Восточная Европа | Српски · Polski · Magyar · Русский |
| Южная/Восточная Азия | हिन्दी · 中文 · Tiếng Việt · Korean (한국어) · 日本語 · Filipino |

Язык переключается мгновенно, без перезапуска.

### Кнопка О программе
Рядом с выбором языка она открывает окно с баннером и сообщением «Эта автономная утилита бесплатна и имеет открытый исходный код.», переведённым на все 15 языков. Окно закрывается клавишей Esc или кнопкой Закрыть. Из пакета `.deb`, AppImage или автономного исполняемого файла небольшая кнопка в левом нижнем углу этого окна добавляет или убирает значок программы (см. ниже).

### Значок меню и рабочего стола
Из пакета `.deb`, AppImage или автономного исполняемого файла при первом запуске открывается окно **«Добавить значок?»** с тремя кнопками: **Добавить**, **Больше не спрашивать** и **Закрыть** (она ничего не запоминает: вопрос появится снова при следующем запуске). Окно напоминает, что позже значок можно будет добавить или убрать кнопкой внизу окна «О программе».
- **Добавить** создаёт пункт **меню приложений** и значок в **папке «Рабочий стол»** без прав администратора. С AppImage и автономным исполняемым файлом программа сначала копируется в `~/.local/share/calculateur-masques/app` (значок сохранится, даже если вы переместите скачанный файл); с `.deb` ничего не копируется.
- **Больше не спрашивать** сохраняет выбор в `~/.config/calculateur-masques/config.json`; удаление значка кнопкой окна «О программе» тоже сохраняет его.
- `.deb` не добавляет никаких значков при установке: его ярлык скрыт, значок появляется только по запросу.

> **GNOME** не показывает значки папки «Рабочий стол» без расширения «Desktop Icons»: значок рабочего стола тогда существует, но остаётся невидимым (программа сообщает об этом). Пункт меню приложений при этом виден.

Чтобы убрать всё вручную:

```bash
rm -r ~/.local/share/calculateur-masques
rm -f ~/.local/share/applications/calculateur-masques.desktop
rm -f ~/.local/share/icons/hicolor/512x512/apps/calculateur-masques.png
rm -f ~/Bureau/calculateur-masques.desktop ~/Desktop/calculateur-masques.desktop
rm -r ~/.config/calculateur-masques
```

### Корейский язык и шрифт
Корейский язык отображается в списке под названием **Korean** (по-английски, поскольку «한국어» без корейского шрифта превратилось бы в квадраты). Если в системе нет такого шрифта, при выборе этого языка открывается диалоговое окно **на английском языке** («Font needed»), которое объясняет, зачем нужен шрифт, и предлагает:
- **команду для копирования** в терминал (установка для всех пользователей): `sudo apt install fonts-noto-cjk` (Debian/Ubuntu), `sudo dnf install google-noto-sans-cjk-fonts` (Fedora), `sudo pacman -S noto-fonts-cjk` (Arch) — проверена только команда для Debian/Ubuntu;
- кнопку **Install automatically**: загружает Noto Sans KR (4,6 МБ, лицензия SIL OFL, зафиксированная версия, контрольная сумма SHA-256 проверяется) в `~/.local/share/fonts/calculateur-masques/` без прав администратора. Это единственный случай, когда программа обращается к сети; в остальное время она работает автономно;
- кнопку **Restart now**: перезапускает программу (с параметром `--lang ko`), чтобы она увидела шрифт; язык меняется при перезапуске. Выбранный язык не сохраняется между сеансами.

Чтобы удалить загруженный шрифт: `rm -r ~/.local/share/fonts/calculateur-masques && fc-cache -f`.

> Для других языков с нелатинской письменностью (хинди, японский, китайский…) такого диалога нет: без подходящего шрифта могут отображаться квадраты. Для японского и китайского: `sudo apt install fonts-noto-cjk`.

## Требования

Python 3.8+ с модулем `tkinter`.

```bash
# Debian / Ubuntu / Linux Mint
sudo apt install python3 python3-tk

# Fedora / RHEL / CentOS
sudo dnf install python3 python3-tkinter

# Arch Linux / Manjaro
sudo pacman -S python tk

# openSUSE
sudo zypper install python3 python3-tk
```

Других зависимостей не требуется.

## Запуск

### Быстрый способ

```bash
chmod +x lancer.sh
./lancer.sh
```

Скрипт автоматически проверяет наличие Python и tkinter и выводит понятное сообщение об ошибке, если какой-либо зависимости не хватает.

### Через Python напрямую

```bash
python3 calculateur_masques.py
```

### Через пакет `.deb` (Debian, Ubuntu, Linux Mint)

Предварительно собранные файлы (`.deb`, AppImage, автономный исполняемый файл и `SHA256SUMS-linux.txt`) публикуются как предварительный выпуск в разделе [Releases](https://github.com/harlockSuites/CalculateurMasques/releases) репозитория под тегом `Linux-v*`; они собраны на Debian 12 (glibc 2.36, Python 3.11, x86-64). Пакет устанавливает программу для всех пользователей:

```bash
sudo apt install ./calculateur-masques_1.0.1_amd64.deb
calculateur-masques
```

Установка не добавляет значок ни в меню, ни на рабочий стол: запустите `calculateur-masques` в первый раз, и окно «Добавить значок?» предложит это сделать. Чтобы удалить:

```bash
sudo apt remove calculateur-masques
```

Пункт меню, добавленный программой, исчезает сам; ярлык на рабочем столе остаётся (это простой файл): уберите его заранее кнопкой окна «О программе» или вручную.

### Через AppImage

Один файл, без установки:

```bash
chmod +x CalculateurMasques-1.0.1-x86_64.AppImage
./CalculateurMasques-1.0.1-x86_64.AppImage
```

Если в системе нет FUSE:

```bash
./CalculateurMasques-1.0.1-x86_64.AppImage --appimage-extract-and-run
```

### Через автономный исполняемый файл

Автономный исполняемый файл (PyInstaller) собирается одной командой (см. ниже «Сборка автономного исполняемого файла»); предварительно собранная версия находится в разделе Releases:

```bash
chmod +x CalculateurMasquesIPv4
./CalculateurMasquesIPv4
```

Чтобы проверить скачанные файлы:

```bash
sha256sum -c SHA256SUMS-linux.txt
```

> **Оговорка о glibc**: эти файлы собраны на Debian 12. Они проверены на этом дистрибутиве; они должны работать и на дистрибутивах с glibc 2.36 или новее, но не на более старых. В таком случае скомпилируйте их из исходного кода.

## Системная установка (необязательно)

Чтобы добавить приложение в меню среды рабочего стола (GNOME, KDE, XFCE…):

```bash
# Скопировать файлы в /opt
sudo mkdir -p /opt/calculateur-masques
sudo cp calculateur_masques.py translations.py lancer.sh icon.png banner.png /opt/calculateur-masques/
sudo chmod +x /opt/calculateur-masques/lancer.sh

# При необходимости изменить путь в файле .desktop
# Exec=bash /opt/calculateur-masques/lancer.sh

# Добавить в меню приложений
sudo cp calculateur-masques.desktop /usr/share/applications/
sudo update-desktop-database   # Debian/Ubuntu
# или
sudo kbuildsycoca6              # KDE Plasma
```

## Сборка автономного исполняемого файла

PyInstaller позволяет создать бинарный файл, не зависящий от Python:

```bash
pip3 install pyinstaller

pyinstaller --onefile --windowed \
    --name CalculateurMasquesIPv4 \
    --add-data "translations.py:." \
    --add-data "icon.png:." \
    --add-data "banner.png:." \
    calculateur_masques.py
```

Исполняемый файл будет создан в `./dist/CalculateurMasquesIPv4`. Параметры `--add-data` встраивают значок окна (загружается во время выполнения через Pillow, если он установлен, иначе средствами Tk) и баннер окна «О программе»; Pillow необязателен (`pip3 install pillow`).

> **Примечание:** бинарный файл Linux, скомпилированный в Ubuntu, не обязательно будет работать в Arch или Fedora из-за различий в версиях glibc. Компилируйте в целевом дистрибутиве или используйте образ Docker нужного дистрибутива.

### Сборка `.deb` и AppImage

В Debian или Ubuntu, при наличии PyInstaller и `appimagetool` в PATH, скрипт сначала собирает каталог PyInstaller, затем оба пакета в `dist/`:

```bash
python3 packaging/build_linux_packages.py
python3 packaging/build_linux_packages.py --only deb
```

Параметр `--only deb` (или `--only appimage`) собирает только один из двух.

## Отличия от версии для Windows

| Аспект | Windows | Linux |
|---|---|---|
| Шрифты | Segoe UI / Consolas | Автоматическое определение (Noto Sans, DejaVu Sans, Liberation…) |
| Колесо мыши | `MouseWheel` (WinAPI) | `Button-4` / `Button-5` (X11) + `MouseWheel` (Wayland) |
| Экспорт CSV | UTF-8 с BOM (Excel) | UTF-8 без BOM (стандарт) |
| Исполняемый файл | Автономный `.exe` | Бинарный файл ELF через PyInstaller (зависит от дистрибутива) |
| Интеграция с рабочим столом | Ярлык Windows | Пакет `.deb`, AppImage, значок меню и рабочего стола (файлы `.desktop`, XDG) |

## Обрабатываемые особые случаи

| Префикс | Поведение |
|---|---|
| `/31` | Канал точка-точка (RFC 3021) — 2 адреса, без обычного broadcast |
| `/32` | Единственный хост — первый = последний = адрес сети |
| `/0` | Универсальная сеть `0.0.0.0` |
